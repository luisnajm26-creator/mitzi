# libros-prueba

Pon aquí tus libros EPUB o PDF para probar Mitzi mientras desarrollas. La app (en el navegador con `npm run dev` y en PC con `npm run electron:dev`) revisa esta carpeta y sus subcarpetas, y muestra los libros en cuanto los copias.

Todo lo que pongas aquí queda fuera de git: los libros nunca se suben al repositorio.

`npm run demo` crea libros de prueba con texto original en `libros-prueba/demo/`.
