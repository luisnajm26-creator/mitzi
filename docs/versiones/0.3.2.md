**Mitzi para Ubuntu**

Primera versión para Ubuntu (Linux), además de Windows y Android. Nada cambia para quien ya usa la 0.3.1 en esos sistemas.

- **Ubuntu:** paquete `.deb` que se instala con `sudo apt install ./Mitzi-0.3.2.deb`. Los libros se buscan en `~/Documentos/Mitzi Libros` y los datos viven en `~/.config/Mitzi`.
- **Ubuntu (Wayland):** Mitzi se abre sola en modo X11, porque en Wayland la biblioteca 3D se veía con bordes dentados y portadas borrosas. Si prefieres otro modo, ábrela con `mitzi --ozone-platform=wayland`.
- **Ubuntu:** se actualiza sola, como en Windows: baja el `.deb`, comprueba su huella y pide tu contraseña del sistema para instalarlo.

**Archivos**
- Windows: `Mitzi-Setup-0.3.2.exe` (Windows puede avisar «Windows protegió tu PC» porque el instalador no tiene certificado: «Más información» › «Ejecutar de todos modos»).
- Android: `Mitzi-0.3.2.apk`.
- Ubuntu: `Mitzi-0.3.2.deb`.
- `SHA256SUMS.txt`: la huella de cada archivo; la app la comprueba antes de instalar.
