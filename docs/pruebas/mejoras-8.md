# Pruebas: el cursor se esconde al leer (PC)

Al leer en la PC, si dejas el ratón quieto unos 2,5 segundos, el cursor desaparece para no distraer. Vuelve en cuanto mueves el ratón.

Al reportar algo, anota: **número de prueba, qué hiciste, qué esperabas, qué pasó** y, si puedes, una captura.

| # | Haz esto | Debe pasar |
|---|---|---|
| 1 | Abre un EPUB, deja el cursor sobre la página y no muevas el ratón | A los 2–3 segundos el cursor desaparece |
| 2 | Mueve el ratón | El cursor aparece al instante |
| 3 | Haz lo mismo con un PDF | Igual: se esconde quieto y vuelve al moverlo |
| 4 | Pasa página con las flechas del teclado sin tocar el ratón | El cursor sigue escondido |
| 5 | Abre **Aa** (Lectura cómoda) o el índice y deja el ratón quieto encima | El cursor **no** se esconde mientras hay un panel abierto |
| 6 | Selecciona texto y deja el ratón quieto con el menú de colores abierto | El cursor no se esconde mientras está el menú |
| 7 | Vuelve a la biblioteca | El cursor funciona normal (en la biblioteca no se esconde) |
